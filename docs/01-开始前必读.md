# 开始前必读

在开始配置前，你需要准备两样东西：API 地址和 API Key。

## 1. 认识示例地址

本文会反复使用下面这个地址：

```text
https://gate.bibilabu.cc
```

它是作者当前使用的 API 平台地址，只用来演示应该填在什么位置。它不是让所有读者直接照抄的通用地址。

如果你使用的是自己的中转站或其他平台，请从该平台的控制台找到 API 地址，并替换所有示例中的地址。例如平台给你的地址是：

```text
https://api.example.com
```

那么 Claude Code 应填写 `https://api.example.com`，Codex 应填写 `https://api.example.com/v1`。不要在地址末尾多加 `/v1`，也不要少加。

## 2. 准备 API Key

在你的 API 平台控制台创建一个新的 API Key。它通常是一串很长的字符，用于确认请求是你发出的。

把 Key 临时保存在本机安全位置，接下来会分别写入 Claude Code 或 Codex 的本地配置文件。示例中的 `YOUR_API_KEY` 只是占位文字，必须替换成你自己的 Key。

## 3. 不要做这些事

- 不要把 API Key 发给他人，也不要粘贴到公开帖子、Issue、聊天记录或截图中。
- 不要把 `auth.json`、`.env`、`settings.json` 上传到 GitHub。它们可能含有你的 Key。
- 不要照抄别人教程中的域名、模型名或额度信息。它们应以你自己的平台控制台为准。

## 4. 先决定使用哪种客户端

| 你的目标 | 应使用的教程 | 原因 |
| --- | --- | --- |
| 在 Claude Code 中使用 Claude 或 GPT 模型 | [Claude Code 配置](02-Claude-Code-配置.md) | 使用 Anthropic Messages 兼容路径 |
| 在 Codex 中使用 GPT 系列模型 | [Codex 配置](03-Codex-配置.md) | 使用 Responses 路径 |
| 在 ChatBox、Cherry Studio、Cline、Roo Code 或代码中调用 | [OpenAI / Anthropic 兼容接入](06-OpenAI与Anthropic兼容接入.md) | 选择客户端支持的协议 |
| 管理和切换多套 Claude Code 配置 | [CC Switch 配置](07-CC-Switch-配置.md) | 图形化管理 Anthropic 类型供应商 |
| 在 Codex 中使用 Claude 模型 | 不建议这样配置 | 已验证的 Responses 路径不支持 Claude 模型 |

完成准备后，只选择其中一个客户端教程往下做。
